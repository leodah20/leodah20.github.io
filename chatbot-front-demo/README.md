# chatbot-front-demo

Protótipo estático (HTML/CSS/JS puro) do painel administrativo do projeto
[chatbot-front](https://github.com/leodah20/chatbot-front), um TCC em grupo.

**Não é funcional** — não há backend, banco de dados ou autenticação real.
Templates Jinja2 originais foram portados para HTML estático com dados
fictícios, só para demonstrar o front-end (HTML, CSS, JS e a estrutura de
templates Flask original).

Fluxo disponível: login (qualquer email/senha) → dashboard → avisos
(busca e ordenação funcionam de verdade, no client-side). Qualquer outra
ação mostra um aviso de que é só protótipo.

Live: https://leodah20.github.io/chatbot-front-demo/
